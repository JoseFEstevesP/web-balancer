## Acerca del Sistema

El Sistema de Gestión es una plataforma completa basada en contenedores Docker que integra varios servicios:

- Frontend (interfaz de usuario)
- Backend (API REST)
- Base de datos PostgreSQL
- Caché Redis
- Servidor web Nginx
- Sistema de respaldo automático

Esta documentación está diseñada para proporcionar información completa a diferentes audiencias, desde usuarios finales hasta desarrolladores y administradores de sistemas.
